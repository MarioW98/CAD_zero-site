# Getting Started
Questa è la pagina di test per la sezione Technical Docs.

Welcome to the CAD_0 technical documentation. This guide will help you choose the right path to interact with the kernel based on your goals.

## Prerequisites

Before building or running CAD_0, ensure your environment meets these minimum requirements:

- **C++20 Compiler**: GCC >= 11 or Clang >= 14. *(Note: MSVC >= 17.10 is listed as a prerequisite, but CI validation primarily targets Linux).*
- **Build System**: CMake >= 3.22 and Ninja.
- **Python (Optional but recommended)**: Python >= 3.10 with development headers installed.

## Choose Your Path

1. **I want to try it instantly without installing anything**  
   Proceed to the [GitHub Codespaces](/technical/codespaces/) guide.
2. **I want to build the C++ kernel locally**  
   Proceed to [Build from Source](/technical/build-from-source/).
3. **I want to script geometry operations**  
   Proceed to the [Python Quickstart](/technical/python-quickstart/).
4. **I want to use the graphical interface**  
   Proceed to the [Desktop App Guide](/technical/desktop-app-guide/).

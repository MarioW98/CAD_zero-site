:::caution[Project Status]
**CAD_0 is an early-stage, research-grade CAD kernel — what exists, the CI testifies.** Available today: the full SDF kernel (primitives, CSG, smooth blends, warps, batched evaluation), radial-edge B-Rep topology, booleans with input-contract gates, the SDF → B-Rep bridge in **both directions** (the inverse watertight-only), the exact B-Rep kernel's first rung (true trimming, exact extrude/subtract, exact mass properties), persistent naming, the sketch → extrude → subtract chain, the `.CAD_0` v0.4.0 project format, Python bindings, and the PySide6 desktop app. **Said, not hidden:** the fillet (G2 units 2–6), patterns, STEP (Phase H), G3 free surfaces, and the sketcher's constraint solver are roadmap items, not current capabilities.
:::

## What is CAD_0?

Most modern CAD systems rely on opaque, heavyweight third-party geometry kernels. CAD_0 is built from the ground up to be an inspectable, educational, and research-grade foundation for computational geometry.

- **Dual Representation:** Native SDF and native B-Rep coexist. The system does not force one to be a derivative of the other.
- **Deterministic by Construction:** Strict floating-point contracts, bit-identical round-trip tests, and `-ffp-contract=off` ensure geometry evaluates identically across supported toolchains.
- **No Third-Party Kernel:** Every boolean, meshing, and topological validation algorithm is implemented natively in C++20.
- **Transparent Architecture:** An ADR-first (Architecture Decision Record) culture ensures every major design choice is documented and traceable.

## Development Roadmap

- ✅ **Phase A:** Core math, geometry, tolerance model.
- ✅ **Phase B:** SDF kernel, marching cubes, vertex welding, twist warp.
- ✅ **Phase C:** Viewport architecture, PySide6 desktop app.
- ✅ **Phase C+:** Native format, migrators, import/export, CI matrix, toolchain contract.
- ✅ **Phase D:** Radial-edge B-Rep topology, query operators, seam wires, convex booleans with contract gates, and the aligned coplanar union sewn by the overlay (ADR-0037).
- ✅ **Phase E:** SDF → B-Rep bridge under hard topology contracts; the inverse bridge's sign is the true generalized winding number, watertight-only, hierarchical over the ε_w-bounded BVH (ADR-0035 D2.4/D2.5).
- ▶️ **Phase F:** Parametric modelling — the boolean feature slice (ADR-0027) and the sketcher MVP (ADR-0030) are in; the constraint solver is deferred with its entry criterion.
- ▶️ **Phase G:** The exact B-Rep kernel — G1 complete (ADR-0032), persistent naming landed (ADR-0036), G2 unit 1 of 6 (the analytic SSI table, ADR-0033) landed; the extended booleans and the fillet follow (ADR-0038, ADR-0039).
- 🔜 **Phase H:** STEP AP203 MVP (ADR-0010).

## Your First Experiment

Verify the kernel in under 5 minutes.

```bash
git clone https://github.com/MarioW98/CAD_zero.git
cd CAD_zero
pip install cmake ninja nanobind scikit-build-core
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCAD_0_BUILD_PYTHON=ON -DCAD_0_BUILD_TESTING=ON
cmake --build build
ctest --test-dir build
cd build/python
python3 -c "
import sys; sys.path.insert(0, '.')
import CAD_0
sph = CAD_0.sdf.sphere(radius=2.0)
print(sph.describe())
mesh = CAD_0.sdf.marching_cubes(sph, resolution=16)
print(f'Vertices: {mesh.vertex_count()}, Triangles: {mesh.triangle_count()}')
"
```
